# Note Link Edge

A **Note Link Edge** is the dashed pointer from a [Note Node](note-node) to the entity or individual
it annotates.

## What you see

A thin dashed line, no arrowhead — a neutral pointer, not a directional assertion. It carries no
label and can't be selected/edited on its own.

## What you can do

Nothing directly on the edge — it's purely a visual consequence of the note being linked. To change or
remove it, use the [Note Node](note-node)'s own **⋮ → Unlink** menu entry, or drag a new connection
from the note to a different element to relink it.
